# Веб-платформа для студии танцев (Dance Studio API)

REST API для управления расписанием занятий и бронирования мест в студии танцев.

## 📋 Описание проекта
Платформа позволяет клиентам просматривать расписание занятий, записываться на них и управлять своими бронированиями. Администраторы могут управлять типами занятий, расписанием и видеть статистику посещаемости.

### Основные возможности:
- Регистрация и авторизация пользователей (JWT).
- Просмотр расписания занятий с фильтрацией.
- Бронирование мест на занятия с проверкой доступности.
- Управление ролями (Клиент / Администратор).

## 🛠 Стек технологий
- **Язык:** PHP 8.3
- **Фреймворк:** Laravel 11
- **База данных:** MySQL
- **Аутентификация:** Laravel Sanctum (JWT)
- **Документация:** Draw.io (ER-диаграмма), Swagger (в разработке)

##  Модель данных
Проект включает следующие основные сущности:
- **Users:** Пользователи системы (клиенты и админы).
- **ClassTypes:** Направления танцев (например, "Балет", "Хип-хоп").
- **ScheduleItems:** Конкретные занятия в расписании (время, дата, вместимость).
- **Bookings:** Записи пользователей на занятия.

Подробная схема базы данных представлена на ER-диаграмме ниже.

## 📂 Структура репозитория
- `/app` — исходный код приложения (модели, контроллеры).
- `/database/migrations` — миграции базы данных.
- `/docs` — документация проекта.
- `/tests` — автоматические тесты.
- `/routes` — определение API маршрутов.
